# RFC e documentação histórica

[Portal do sistema](../../README.md) · [Índice técnico](../README.md)

Esta pasta guarda a proposta acadêmica anterior à centralização do sistema.

- [RFC original preservada — v1.5](RFC_v1.5_original.md).

**Importante:** o título, o identificador da versão e o estado de implementação no documento original refletem o período em que foi escrito. O texto foi preservado **sem revisão editorial ou atualização de promessas** nesta etapa. Trechos que descrevem Unity, API ou dashboard como ainda não demonstrados precisam ser confrontados com os registros posteriores dos Marcos 03 e 04; trechos que propõem alertas clínicos, políticas de segurança ou novos modelos de dados não comprovam que foram implementados.

Após o fechamento da documentação central, a RFC poderá ser atualizada numa nova versão, com rastreabilidade entre requisitos, código, evidências e limitações. Não alterar este arquivo preservado; criar uma versão nova.
